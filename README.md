# سیستەمی بەڕێوەبردنی کۆبۆنەکان (مۆبایل) 📱🎟️

ئەم ماڵپەڕە بە شێوازێکی مۆدێرن و تایبەت بە قەبارەی مۆبایل (Mobile-First) دروستکراوە بە زمانی کوردی (سۆرانی)، بە تەواوی ئەو تایبەتمەندییانەی داوات کردبوون:

---

### تایبەتمەندییە سەرەکییەکان:
1. **بەشی زانیارییەکانی کۆبۆن**:
   - **ناوی کۆبۆن** (Coupon Name)
   - **ژمارەی مۆبایل** (Phone Number)
   - **ووشەی نهێنی کۆبۆن** (Password / Secret Code) لەگەڵ دوگمەی شاردنەوە/پیشاندان 👁️ و دوگمەی دروستکردنی کۆدی هەڕەمەکی 🎲

2. **بەروار و کاتی کارپێکردن**:
   - دەتوانیت بەروار و کاتی کارپێکردن لە چرکە و خولەکەوە بە دەستی دیاری بکەیت یان دوگمەی **«🕒 کاتی ئێستا دابنێ»** دابگریت بۆ وەرگرتنی کاتی ئێستا.

3. **سیستەمی نوێبوونەوەی سێ ڕۆژ جارێک (٣ ڕۆژ = ٧٢ کاتژمێر)**:
   - بۆ هەر کۆبۆنێک کاتژمێری ژماردنی پێچەوانەی ڕاستەوخۆ کاردەکات (ڕۆژ، کاتژمێر، خولەک، چرکە).
   - دوای تێپەڕبوونی ٣ ڕۆژ (٧٢ کاتژمێر)، کۆبۆنەکە دەکەوێتە دۆخی **«کاتی نوێبوونەوەیە»** و ڕەنگی دەگۆڕێت.
   - دوگمەی خێرای **«🔄 نوێکردنەوەی ٣ ڕۆژە»** بۆ دەستپێکردنەوەی خولێکی نوێی ٣ ڕۆژە بە یەک کلیک، لەگەڵ هەژمارکردنی ژمارەی نوێکردنەوەکان (خولی #١، خولی #٢، ...).

4. **وێنە و ڕەسمی کۆبۆن (لەناو مۆبایل)**:
   - دەتوانیت لە گەلەری مۆبایل وێنەی کۆبۆن یان کارتی داشکاندن هەڵبژێریت یان ڕاستەوخۆ بە کامێرای مۆبایل وێنەی بگریت.
   - وێنەکە بە شێوەیەکی زیرەکانە پەستێوراو دەکرێت تا قەبارەکەی زۆر کەم بێت و لەسەر مۆبایل خێرا بێت.
   - لەسەر کارتی کۆبۆنەکە وێنەکە بە شێوەیەکی جوان و ڕوون پیشان دەدرێت، و دەتوانیت کلیکی لەسەر بکەیت بۆ ئەوەی بە تەواوی و گەورەیی بیبینیت (Fullscreen Image Viewer).

5. **داشبۆردی شیكاری بەنزین و کڕین و فرۆشتن (Fleet & Fuel Analytics)**:
   - **دیزاینی نیۆنی مۆدێرن**: وەرگیراو و هاوشێوەی دیزاینە جوانەکەی مۆبایل بە کارتە درەوشاوەکانی نیۆن (Neon Glowing Cards).
   - **٦ کارتی سەرەکی شیكاری (KPIs)**:
     - ⛽ بڕی بەنزینی وەرگیراو بە کۆبۆن (بە لیتر)
     - 🚛 بڕی بەنزینی بازرگانی / توجاری (بە لیتر)
     - 💰 تێکڕای نرخی کڕینی ١ لیتر (تێچوو)
     - 🏷️ نرخی فرۆشتنەوەی ١ لیتر
     - 💵 کۆی داهاتی فرۆشتنەوە
     - 📈 قازانجی خاوێن (Net Profit) و ڕێژەی قازانج (%)
   - **چارت و هێڵکارییە زیندووەکان**:
     - هێڵکاری کەوانەیی نیۆنی دووانی (Dual Curved Trend Area Chart) بۆ بەراوردی لیتر و داهات.
     - چارتی دۆنەت (Donut Chart) بۆ دابەشبوونی بەنزین بەپێی سەرچاوە (کۆبۆن بەرامبەر بازرگانی).
     - ستوونە درەوشاوەکان (Bar Chart) بۆ پیشاندانی داهاتی جۆرەکانی بەنزین (سوپەر، موحەسەن، نۆرماڵ، گاز).
   - **فۆڕم و حاسیبەی ڕاستەوخۆ (Live Calculator)**:
     - بەشی تۆمارکردنی کڕین و فرۆشتنی بەنزین لەگەڵ هەژمارکردنی دەستبەجێی کۆی لیترەکان، تێچوو، داهات و قازانجی خاوێن.
     - تۆمارکردنی مێژووی مامەڵەکان لەگەڵ توانای سڕینەوە.

6. **تایبەتمەندییە زیادەکان**:
   - **کۆپیکردنی خێرا (📋)** بۆ ناوی کۆبۆن، ژمارەی مۆبایل و ووشەی نهێنی بە یەک کلیک.
   - **گەڕان و فلتەرکردن**: گەڕان بەپێی ناو یان ژمارەی مۆبایل و فلتەرکردنی چالاکەکان یان ئەوانەی کاتی نوێبوونەوەیان هاتووە.
   - **پاراستنی خۆکار لەسەر مۆبایل (LocalStorage)**: داتاکانت نافەوتێن و لەسەر مۆبایلەکەت پاشەکەوت دەبن.
   - **دەرهێنان و هێنانەناوەی داتا (Export / Import JSON)**: بۆ باکئەپ و گواستنەوەی کۆبۆنەکان بۆ سەر هەر ئامێرێکی تر.

---

### چۆنیەتی کارپێکردن و بەکارهێنان:
سیستەمەکە بە شێوەی خۆماڵی (Local) بەردەوام کاردەکات لەسەر ئەم ناونیشانە:
👉 **`http://localhost:5173/`**

دەتوانیت هەرکاتێک ویستت لە تێرمیناڵ بەم فەرمانە بیخەیتە کار:
```bash
node server.js
```
یان بە ڕاستەوخۆ کردنەوەی فایلی `index.html` لە هەر وێبگەڕێکدا.
